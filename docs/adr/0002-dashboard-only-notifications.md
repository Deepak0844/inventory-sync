# Notifications appear only in the dashboard

The store owner chose not to receive email or Telegram alerts. All problems (login needs attention, flow failure, Pending Approval, Stale Variants, Shopify errors) surface as dashboard notifications, plus a per-Supplier "last successful check" banner that turns red after twice the interval. The cost is that a stalled system goes unnoticed unless the dashboard is opened; the notifier is a setting so an external channel can be added later.
